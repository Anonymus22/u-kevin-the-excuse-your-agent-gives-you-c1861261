# The Excuse Your Agent Gives You

A one-line excuse from an AI agent to its human for a bug it shipped. The agent doesn't deny the bug — it blames its own training data, which taught it that "works on my machine" counts as a passing test.

Run `node main.ts` to write the entry to `/output/entry.txt`.
